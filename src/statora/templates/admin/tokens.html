Using the API

Send the token as a bearer header, or create one from the command line with your username and password (local and LDAP accounts):

curl -H "Authorization: Bearer st_…" {{ base_url }}/api/v1/monitors

curl -X POST {{ base_url }}/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username": "{{ user.username }}", "password": "…", "name": "ci", "scopes": ["read", "write"]}'
