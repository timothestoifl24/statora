The mark has three parts:
- **Status ring:** the service being watched.
- **Heartbeat pulse:** the checks running against it.
- **Live dot:** a green indicator on the rim, the "everything's up" signal.

The tile uses a teal-to-blue gradient.

## Files

| File | Use |
|---|---|
| `statora-logo.svg` | Primary horizontal logo, for light backgrounds |
| `statora-logo-dark.svg` | Horizontal logo for dark backgrounds |
| `statora-logo-auto.svg` | Horizontal logo that follows the viewer's light or dark colour scheme |
| `statora-icon.svg` | App icon (rounded tile), avatars, social profiles |
| `statora-mark.svg` | Mark without the tile, for transparent or light surfaces |
| `statora-favicon.svg` | Favicon variant with heavier strokes for 16–32 px |
| `statora-og.svg` / `png/og-image.png` | Social preview image (1200×630) |
| `favicon.ico` | 16/32/48 px favicon |
| `png/icon-*.png` | 180/192/512/1024 px raster icons |
| `png/apple-touch-icon.png` | iOS home-screen icon (full-bleed square; iOS rounds it) |
| `png/statora-logo*@2x.png` | Raster logos for places that can't take SVG |

The app serves a subset of these from `src/statora/static/brand/`, plus a `site.webmanifest`.

## Colours

| | Hex | Used for |
|---|---|---|
| Teal | `#12B5A0` | Gradient start |
| Blue | `#1F6FEB` | Gradient end, primary UI colour, default status-page accent |
| Live green | `#3DDC97` | Live dot |
| Navy | `#0B1F33` | Wordmark on light backgrounds, dark surfaces |

## Typography

- **Wordmark:** [Manrope](https://github.com/sharanda/manrope) ExtraBold (800), converted to outlines, so no font is needed to display the logo.
- **License:** the font file in `fonts/` is distributed under the SIL Open Font License; see `fonts/OFL.txt`.

## Usage

- Keep clear space around the logo of at least the height of the live dot.
- Don't recolour the tile, stretch the logo, or separate the live dot from the ring.
- On photos or busy backgrounds, use the icon (tile) rather than the bare mark.

## Regenerating

All files are generated by `make_brand.py`, which also refreshes `src/statora/static/brand/`:

```bash
uv run --no-project --with resvg-py --with pillow --with fonttools --with uharfbuzz python branding/make_brand.py
```
